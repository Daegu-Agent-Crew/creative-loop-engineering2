# PLAN — 밈코인 발행 장기 계획

## 실행 계획

### Phase 1: 기존 자산 정리
- **담당**: 대구루
- **입력**: ai-solana-agent 리포(관측 데이터, DApp 1~3, PRE-REGISTRATION), CLE2-25/29 기록
- **출력**: 자산 현황 문서(무엇이 살아 있고 무엇을 고쳐야 재가동되는지)
- **예상 시간**: 1회 세션

### Phase 2: 로드맵 작성
- **담당**: 대구루
- **입력**: Phase 1 산출물, 컴플라이언스 가드레일 6항목
- **출력**: 재개 트리거(시장·콘텐츠·자금)·단계(관측 재개→페이퍼→실발행)·단계별 승인 게이트 정의
- **예상 시간**: 1회 세션

### Phase 3: 회장님 승인
- **담당**: 회장님
- **입력**: 로드맵 문서
- **출력**: 승인 또는 수정 지시
- **예상 시간**: 리뷰 1회
