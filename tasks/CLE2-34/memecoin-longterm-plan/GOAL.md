# GOAL — 밈코인 발행 장기 계획

## 목표
밈코인 발행(CLE2-25/29 계보)을 재개 트리거·단계·승인 게이트가 정의된 장기 로드맵으로 재정립하여, 후순위 기간에도 재개 판단을 즉시 할 수 있게 한다.

## 가치 가설
- 사용자 가치: 회장님이 시장·콘텐츠 조건 충족 시 "재개/보류"를 근거로 한 번에 결정할 수 있다
- 기본 목표: 재개 트리거 3종·단계 3단계·게이트 기준이 문서로 존재
- 도전 목표: 기존 관측 데이터와 DApp 자산이 재개 시 1주일 내 재가동 가능한 상태로 정리됨

## 성공 기준 (Definition of Done)
- [ ] 로드맵 문서(재개 트리거·단계별 게이트) 작성 및 회장님 승인
- [ ] ai-solana-agent 관측 데이터·DApp 3종 현황 정리 문서 작성
- [ ] 컴플라이언스 가드레일 6항목 재확인 조항 포함
- [ ] 실발행 전 회장님 승인 게이트 명문화

## 범위
### 포함 (In Scope)
- 장기 로드맵 문서, 기존 자산 정리, 재개 조건 정의

### 제외 (Out of Scope)
- 실제 발행 실행, 실거래, 관측 재개 실행(별도 승인 필요)
