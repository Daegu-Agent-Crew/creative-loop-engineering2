# GOAL — CLE5 개발 계획: 자기성장형 창작 에이전트 시스템

## 목표
CLE4의 감각 기반 창작 철학과 파이프라인을 계승하고, 피드백·자기평가·사례·원칙 개정이 다음 작업에 다시 반영되는 자기성장형 창작 에이전트 시스템 `CLE5`의 개발 계약을 수립한다.

## 가치 가설
- 사용자 가치: 회장님은 반복해서 철학과 취향을 설명하지 않고 입력과 핵심 피드백에 집중할 수 있다.
- 기본 목표: 세션이 바뀌어도 이전 실패와 좋은 판단을 파일에서 상속하고 같은 실패의 반복 여부를 검증한다.
- 도전 목표: 반복 실패율과 재작업은 줄이면서도 체크리스트가 계속 비대해지지 않는 성장 루프를 만든다.

## 성공 기준 (Definition of Done)
- [ ] CLE4와 CLE5의 경계 및 선택적 마이그레이션 원칙이 문서화된다.
- [ ] 피드백 태깅 → 자기평가 → 사례 등록 → 승격/은퇴 → 시스템 개정의 G1~G5 실행 계약이 정의된다.
- [ ] feedback tag, case, self-assessment, principle revision 데이터 형식과 자동 검증 기준이 정의된다.
- [ ] 작가와 비평가가 분리된 호출 계약 및 사람 승인 지점이 정의된다.
- [ ] 새 세션이 이전 경험을 상속하는 부팅 순서와 컨텍스트 예산 규칙이 정의된다.
- [ ] CASE-0001을 포함한 시범 데이터로 한 번의 성장 루프를 재현한다.
- [ ] 반복 실패율, 자기평가-사람 피드백 간극, 재작업 횟수와 체크리스트 크기를 관측할 수 있다.
- [ ] CLE2에서 목표, Discovery, 계획, 상태, 테스트와 결정을 조회할 수 있다.

## 범위
### 포함 (In Scope)
- CLE5 시스템 경계와 저장소/파일 구조 설계
- 파일 기반 memory, feedback tag, case library와 principle lifecycle
- Growth Loop 실행기와 검증기 설계
- CLE4 자료의 출처를 보존한 선택적 마이그레이션
- 한 에피소드 시범 적용과 성장 증거
- GitHub Issue/PR 기반 변경 이력 및 사람 승인

### 제외 (Out of Scope)
- 기반 모델 파인튜닝 또는 모델 자체의 영구 학습
- CLE4 전체 결과물의 일괄 변환
- 전체 만화 에피소드 제작
- 미학적 판단의 완전 무인 최종 승인
- CLE5 웹 UI의 즉시 완성
