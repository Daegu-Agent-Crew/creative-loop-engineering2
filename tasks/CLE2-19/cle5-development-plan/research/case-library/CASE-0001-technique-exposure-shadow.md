# CASE-0001: 태양을 그리지 않고 그림자를 그린다

## 메타

- **에피소드**: EP003 / 패널: p1-4 (구 패널 1)
- **영역**: 패널구성
- **주 태그**: 기교노출
- **보조 태그**: 감각부재
- **출처**: 자기평가 (CLE3 → CLE4 전환 설계 과정)
- **유형**: 실패→수정
- **등록일**: 2026-08-03

## Before

```
패널 1 (CLE3): 풀샷으로 태양 세 개가 뜨는 하늘.
드라마틱한 광원 효과, 인물들이 하늘을 올려다보는 리액션 샷.
프롬프트: "세 개의 태양이 뜨는 풍경, 만화 스타일, 최고 화질, 마스터피스"
```

## After

```
패널 1 (CLE4): 태양 세 개의 빛이 만드는 그림자만 그린다.
세 방향으로 갈라진 그림자. 인물은 그림자 교차점에 서 있다.
하늘은 프레임 밖. 태양은 한 번도 직접 보이지 않는다.
그림자가 하늘을 말한다.
```

## 왜 (김환기 원칙의 언어로)

Before는 "세 개의 태양"이라는 **개념**을 그렸다 — 관객에게 "이것이
충격적인 장면입니다"라고 과시하는 구도다. 기교가 보인다. After는
태양이 남긴 **흔적**(그림자)을 그린다. "꽃의 개념이 생기기 전"으로
돌아간 것이다. 충격은 화면이 소리치는 데서 오지 않고, 관객이 그림자의
분열을 스스로 해독하는 순간에 온다. 닭이 알을 낳듯이 — 과시하지 않고
존재하는 것. (원칙 1 감각의 기억, 원칙 3 무심함의 미학)

## 재현 조건

"장면의 핵심 대상(태양, 괴물, 폭발…)을 정면 풀샷으로 그리려는
충동이 들 때 — 그 대상이 남기는 흔적으로 대체 가능한지 먼저 묻는다."
