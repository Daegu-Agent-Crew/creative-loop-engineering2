# DISCOVERY — CLE5 독립 연재 만화 제작 시스템

## 실제 기준선
- CLE5는 텍스트 작품의 원본 → 피드백 → 수정 → 기억 승인 흐름을 제공한다.
- Agent Handoff URL과 marked plain-text 반환 계약이 이미 있다.
- Workspace 전체를 localStorage와 GitHub Contents API로 저장할 수 있다.
- 이미지·에피소드·패널·발행 데이터 모델과 UI는 없다.

## Unknown Map

### Known Known
- CLE5의 단순한 현재 작업 중심 UX는 유지해야 한다.
- 이미지 생성은 외부 에이전트가 수행하고 결과 URL 또는 저장 경로를 반환할 수 있다.
- Pages 앱은 서버 없이 동작하므로 이미지 바이너리보다 URL·저장소 경로 중심 등록이 적합하다.
- 사람 승인 전 후보는 다음 작업의 기억이 되어서는 안 된다.

### Known Unknown
- 대량 이미지 원본을 장기적으로 GitHub 또는 외부 저장소 중 어디에 보관할지
- 에이전트별 이미지 결과 반환 방식의 차이
- 첫 실제 연재 프로젝트의 패널 수와 발행 주기

### Unknown Known
- 사용자가 패널 제작에서 암묵적으로 우선하는 품질 순위
- 후보 선택 시 실제로 반복되는 판단 언어
- 모바일 검토에서 필요한 이미지 확대 수준

### Unknown Unknown 후보
- Workspace JSON이 이미지 메타데이터 증가로 비대해질 위험
- 외부 URL이 만료되어 과거 에피소드가 깨질 위험
- 범용 창작 모드와 만화 모드가 한 UI에서 충돌할 위험
- 자동으로 누적된 기억이 특정 화풍에 과적합될 위험

## 실행 판단
- 기존 텍스트 Workspace는 유지하고 `Comic`을 별도 1차 사용자 경로로 추가한다.
- 저장 데이터는 한 Workspace에 두되 comicProjects를 독립 컬렉션으로 관리한다.
- 이미지 후보 선택은 브라우저 로컬에 즉시 저장하고 기존 GitHub 동기화로 영속화한다.
- CLE3는 구현 참고 자료로도 import하지 않으며 CLE5 자체 계약으로 새로 작성한다.
