# PLAN — CLE5 독립 연재 만화 제작 시스템

## Phase 1 — 요구사항과 데이터 기반
- CLE2-21 Issue/표준 문서
- Workspace v3 마이그레이션
- Project/Episode/Artifact/Panel/Review/Publish 계약

## Phase 2 — Comic Workspace
- 프로젝트·에피소드 선택
- `구성 → 제작 → 검토 → 발행` 단계 레일
- 현재 상태, 다음 작업과 주요 실행 버튼
- 기술 데이터는 기본 화면에서 숨김

## Phase 3 — 산출물과 Agent Handoff
- 캐릭터, 콘티, 패널 URL·저장 경로 등록
- 만화 작업 종류별 Agent Brief
- 이미지 작업 반환용 Asset 계약
- CLE5 내부 목표 경로 명시

## Phase 4 — 수렴과 기억
- 기준선/후보 A/B 비교
- 선택, 동점, 모두 탈락
- 선택 근거와 패널 QA
- 승인 후보만 project/episode/character 범위 기억으로 승격

## Phase 5 — 발행
- 패널 순서와 대사·자막 관리
- 발행 준비 게이트
- 모바일 세로 만화 뷰어
- 공개 링크

## Phase 6 — 검증과 배포
- 단위 테스트와 기존 CLE5 회귀
- 데스크톱·모바일 브라우저 QA
- CLE3 문자열·네트워크 의존성 검사
- CLE5/CLE2 PR과 Pages 배포

## 사람 승인 게이트
- 후보 이미지 최종 선택
- 범위별 기억 승인
- 발행 전 최종 QA
