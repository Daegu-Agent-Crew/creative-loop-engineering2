# DECISIONS — CLE5 독립 연재 만화 제작 시스템

## D-001 — CLE5가 만화 제작 전체를 직접 소유
- 결정일: 2026-08-15
- 결정: 프로젝트, 에피소드, 산출물, 수렴, QA, 기억과 발행 데이터를 CLE5 저장소와 Workspace가 소유한다.
- 이유: CLE3 의존을 제거하면서 CLE5의 사람-AI 창작 루프를 실제 결과물까지 확장한다.
- 사람 승인: approved

## D-002 — 기존 텍스트 Workspace를 보존
- 결정일: 2026-08-15
- 결정: 기존 `Work` 흐름은 삭제하지 않고 `Comic`을 독립 경로로 추가한다.
- 이유: 이미 작동하는 성장 루프와 일반 창작 용도를 회귀시키지 않는다.

## D-003 — 이미지는 외부 에이전트가 생성
- 결정일: 2026-08-15
- 결정: CLE5 브라우저는 이미지 생성 API를 소유하지 않는다. Agent Handoff가 맥락, 참조 URL, 목표 경로와 반환 계약을 제공한다.
- 이유: Codex·Claude·OpenClaw 등 도구를 가진 에이전트를 활용하고 브라우저 비밀키·비용·제공자 종속을 피한다.

## D-004 — 사람 승인만 기억을 만든다
- 결정일: 2026-08-15
- 결정: 후보 선택과 근거가 명시된 경우에만 승인 패널 및 판단을 기억에 추가한다. 동점·모두 탈락은 이력만 남긴다.
- 이유: 모델 추천이 자기강화되어 취향 기억을 오염시키는 것을 막는다.

## D-005 — JSON은 내부 형식
- 결정일: 2026-08-15
- 결정: 사용자와 에이전트는 화면, URL과 plain-text 반환 계약을 사용한다. JSON은 저장·검증에만 사용한다.
- 이유: CLE5의 단순한 사용자 경험을 유지한다.

## D-006 — 이미지 원본도 CLE5-native로 생성
- 결정일: 2026-08-15
- 결정: 예제 캐릭터와 패널 후보는 CLE5용으로 새로 생성하고 `app/assets/comic/`에 WebP로 저장한다.
- 이유: 다른 만화 저장소의 창작 자산을 재사용하지 않고 시스템 경계를 데이터까지 일치시킨다.

## D-007 — 발행은 패널 단위 QA가 모두 통과해야 함
- 결정일: 2026-08-15
- 결정: 사람 선택과 구도·캐릭터·연속성·대사 분리 QA가 모두 통과한 패널만 세로 독자 화면과 발행 게이트에 포함한다.
- 이유: 생성 완료와 연재 가능 상태를 분리하고 불량 패널만 국소적으로 수정한다.
