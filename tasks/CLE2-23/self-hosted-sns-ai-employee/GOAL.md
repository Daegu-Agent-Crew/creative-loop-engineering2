# GOAL — 자체 호스팅 SNS AI 직원 시스템 (Spark 클론)

## 목표
회원가입·유료 외부 서비스(Blotato, Higgsfield, 커뮤니티 프롬프트 팩) 없이, 자체 API와 자체 프롬프트로 콘텐츠 생성 → 사람 승인 → 멀티 계정 게시 → 자동 DM까지 동작하는 SNS AI 직원 시스템을 자체 호스팅으로 구축한다.

## 가치 가설
- 사용자 가치: SNS 운영을 하나의 로컬 대시보드에서 처리하며, 외부 SaaS 구독비와 계정 의존 없이 자산화된 프롬프트·코드로 반복 활용 가능
- 기본 목표: 캐러셀 생성 + 사람 승인 + 1개 플랫폼 게시 + 트리거 워드 댓글 답변까지 동작하는 MVP
- 도전 목표: 멀티 플랫폼 게시 + 자동 DM 발송 + 실적 리포트까지 통합된 명령 센터

## 성공 기준 (Definition of Done)
- [ ] 주제 입력 → 자체 프롬프트+생성 API로 5~10장 캐러셀 자동 생성
- [ ] 승인 탭에서 승인/편집/거절/재생성 워크플로우 동작 (승인 없이 게시 불가)
- [ ] 최소 1개 플랫폼(X 또는 LinkedIn)에 자체 게시 게이트웨이로 게시 성공
- [ ] 댓글 모니터링 → 트리거 워드 감지 → 댓글 답변(3변형 랜덤) 자동 발송
- [ ] 자동 DM 발송 또는 플랫폼 제약 분석에 따른 폴백 동작 문서화
- [ ] 자체 프롬프트 팩(prompts/)이 repo에 자산으로 저장되어 재사용 가능
- [ ] 대시보드에서 생성/승인/캘린더/실적 리포트 확인 가능

## 범위
### 포함 (In Scope)
- 콘텐츠 생성 API (캐러셀/이미지/숏폼), 자체 프롬프트 라이브러리
- 멀티계정 게시 게이트웨이 (공식 API 우선 + 브라우저 자동화 폴백)
- 자동 DM 엔진 (트리거 워드 감지, 댓글 답변, DM 발송)
- 승인 워크플로우, 캘린더, 리포트 대시보드
- 딜 칸반 (선택, 후반 Phase)

### 제외 (Out of Scope)
- 타인 판매용 SaaS화 (영상 v2 로드맵, 별도 요구사항)
- 유료 커뮤니티 완성품의 복제/유통
- 광고 집행 관리
