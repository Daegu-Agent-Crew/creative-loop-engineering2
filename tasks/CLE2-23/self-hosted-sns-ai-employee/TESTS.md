# TESTS — 자체 호스팅 SNS AI 직원 시스템 (Spark 클론)

## 검증 기준

### 기능 테스트
| # | 테스트 항목 | 방법 | 기대 결과 | 통과 |
|---|------------|------|-----------|------|
| 1 | 캐러셀 생성 | 대시보드에서 주제/디자인/장수(5~10) 입력 | 지정 장수의 슬라이드 이미지 생성, 승인 탭에 표시 | ⬜ |
| 2 | 승인 게이트 | 승인 없이 게시 시도 | 게시 발송 불가 (승인 필수 검증) | ⬜ |
| 3 | 승인 → 게시 | 승인 후 첫 플랫폼 게시 | 게시물 URL 반환, 계정에 실제 반영 | ⬜ |
| 4 | 재생성/거절 | 승인 탭에서 거절·재생성 선택 | 상태 전환 및 재생성 동작 | ⬜ |
| 5 | 트리거 워드 감지 | 테스트 게시물에 트리거 워드 댓글 작성 | 설정 시간 내 감지 (설계 목표 ≤2분) | ⬜ |
| 6 | 댓글 자동 답변 | 감지 후 답변 확인 | 3개 변형 문구 중 랜덤 1개로 답변 등록 | ⬜ |
| 7 | 자동 DM | 감지 후 DM 확인 또는 제약 분석 | DM 발송 성공 또는 폴백 동작 문서 준수 | ⬜ |
| 8 | 실적 카운터 | 답변/DM 발송 후 리포트 확인 | 카운터·리포트 정확 반영 | ⬜ |
| 9 | 프롬프트 팩 재사용 | prompts/ 프롬프트로 동일 품질 재생성 | 재현성 확보 (버전 고정) | ⬜ |
| 10 | 멀티 플랫폼 확장 | 2번째 플랫폼 어댑터 연결 | 동일 승인 파이프라인으로 게시 | ⬜ |

### 비기능 테스트
| # | 테스트 항목 | 방법 | 기대 결과 | 통과 |
|---|------------|------|-----------|------|
| 1 | 스팸 안전 | 연속 트리거 워드 다발 입력 | 속도 제한 동작, 계정 제재 없음 | ⬜ |
| 2 | 어댑터 교체성 | 생성 백엔드를 다른 API로 교체 | 코드 변경 최소화로 동작 (인터페이스 유지) | ⬜ |
| 3 | 자체 호스팅 | 외부 SaaS 콜 없이 전 파이프라인 구동 | Blotato/Higgsfield/커뮤니티 의존 0 | ⬜ |

# 생성 API 유닛 테스트, 게시 큐 dry-run, 트리거 감지 시뮬레이터
