# PLAN — 자체 호스팅 SNS AI 직원 시스템 (Spark 클론)

## 실행 계획

### Phase 1: 아키텍처 설계 + 자체 프롬프트 팩 초안
- **담당**: 대구루
- **입력**: 이슈 #65 요구사항, 영상 요약(2026-08-24), 기존 browser-automation 인프라
- **출력**: 시스템 아키텍처 문서(모듈 다이어그램, API 명세 초안), `prompts/` 폴더 프롬프트 팩 v1 (캐러셀 기획/캡션/해시태그/DM 문구/댓글 답변 변형)
- **예상 시간**: 1~2일

### Phase 2: 콘텐츠 생성 API + 대시보드 MVP
- **담당**: 대구루
- **입력**: Phase 1 아키텍처 + 프롬프트 팩
- **출력**: 생성 어댑터(GLM/OpenAI 호환, 로컬 SD 등 교체 가능) + 웹 대시보드 (생성 폼 → 승인 탭 → 상태 추적)
- **예상 시간**: 3~5일

### Phase 3: 게시 게이트웨이 (첫 플랫폼 1개)
- **담당**: 대구루
- **입력**: Phase 2 대시보드, 플랫폼 공식 API 키 (X 또는 LinkedIn — 회장님 확보 결정 필요)
- **출력**: 게시 어댑터 + 게시 큐 + 재시도, 승인 게이트 통합 (승인 시에만 발송)
- **예상 시간**: 3~5일

### Phase 4: 자동 DM 엔진
- **담당**: 대구루
- **입력**: Phase 3 게시 파이프라인, 트리거 워드 설정 UI
- **출력**: 댓글 모니터링(폴링/웹훅) → 트리거 감지 → 댓글 답변(3변형 랜덤) + DM 발송 or 폴백, 실적 카운터
- **예상 시간**: 3~5일 (플랫폼 DM API 제약 검증 포함)

### Phase 5: 캘린더·리포트 + 멀티 플랫폼 확장
- **담당**: 대구루
- **입력**: Phase 1~4 자산
- **출력**: 예약 게시 캘린더, DM·게시 실적 리포트, 플랫폼 어댑터 추가(Instagram Graph/TikTok), 딜 칸반(선택)
- **예상 시간**: 3~5일

## 의존성
- 플랫폼 공식 API 키 발급 (X API, LinkedIn API 등 — 회장님 계정/승인 필요)
- Instagram DM 자동 발송은 Business API 정책 제약 → Phase 4에서 검증
- 생성 모델 API (보유 GLM/OpenAI 호환 키)

## 도구 및 접근
| 도구/데이터 | 목적 | 접근 상태 | 대안 |
|---|---|---|---|
| GLM/OpenAI 호환 생성 API | 콘텐츠 카피·기획 생성 | available | 로컬 모델 |
| 이미지 생성 API | 캐러셀/이미지 렌더링 | available | 로컬 Stable Diffusion |
| X/LinkedIn 공식 API | 게시·댓글 조회 | missing (키 필요) | 브라우저 자동화 폴백 |
| Instagram Graph API | 게시·DM | restricted | 브라우저 자동화 폴백, 기능 축소 |
| browser-automation 인프라 | API 미지원 플랫폼 폴백 | available | — |

## 리스크
- 플랫폼 API 정책 변경/제한(특히 DM) → 어댑터 추상화로 폴백 전환, 기능 축소
- 자동화 계정 제재(스팸 오탐) → 발송 속도 제한, 사람 승인 게이트 유지
- 생성 품질 불안정 → 프롬프트 팩 버저닝 + A/B 개선 루프
