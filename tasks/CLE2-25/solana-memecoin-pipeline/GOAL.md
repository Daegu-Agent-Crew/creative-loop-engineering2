# GOAL — 솔라나 밈코인 발행·DEX 등록·이벤트 마케팅 파이프라인

## 목표
교육·데모·관측 목적으로 솔라나 밈코인을 투명하게 발행·등록하고, 사실 기반 커뮤니티 이벤트 마케팅 적용 시 온체인 지표가 어떻게 반응하는지 정량 관측한다. 수익 추출이 목적이 아니다.

## 가치 가설
- 사용자 가치: 밈코인 발행 → 유동성 → DEX 노출 → 마케팅 → 관측의 전 과정을 실습으로 습득 (CLE2-14 Solana DApp 역량 확장)
- 기본 목표: devnet 전 사이클 완주 + mainnet 최소 규모 데모 + DexScreener 자동 인덱싱 확인
- 도전 목표: 이벤트 마케팅 전후 지표 변화 비교 리포트 자동화 (관측 대시보드)

## 성공 기준 (Definition of Done)
- [ ] devnet 발행~풀 생성~스왑 자동화 스크립트 완성
- [ ] mainnet 토큰 발행 + LP 풀 생성 (루트 A/B, 회장님 승인 후)
- [ ] DexScreener(또는 GeckoTerminal) 자동 인덱싱 확인 증거 확보
- [ ] LP 소각/락 온체인 증거 확보
- [ ] 관측 대시보드에서 가격·거래량·홀더 수 확인
- [ ] 사실 기반 이벤트 마케팅 1회 실행 + 전후 지표 비교 리포트
- [ ] 컴플라이언스 체크리스트 전 통과 (순환거래 0, 허위 공시 0, 고지 문구 게시)

## 범위
### 포함 (In Scope)
- SPL Token-2022 + Metaplex 발행, pump.fun / Raydium CPMM 루트 비교 실습
- DexScreener 자동 노출 검증, 관측 대시보드, 사실 기반 이벤트 마케팅 1회
- CYBERLEEK($LEEK) 사례 온체인 분석 문서화

### 제외 (Out of Scope)
- 수익 추출/전량 매도 전략, KRW 전환 경로 구축
- 허위 정보 유포, 타인 이슈·범죄 편승 마케팅, 인플루언서 유급 홍보
- 중앙화 거래소(CEX) 상장
