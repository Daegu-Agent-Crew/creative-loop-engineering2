# PLAN — 솔라나 밈코인 발행·DEX 등록·이벤트 마케팅 파이프라인

## 실행 계획

### Phase 0: devnet 리허설
- **담당**: 대구루
- **입력**: 발행 스펙 (10억 개 / 6 decimals / 과세·동결 권한 없음 / 민트 권한 폐기)
- **출력**: devnet 발행~풀 생성~스왑 자동화 스크립트 + 실행 로그
- **예상 시간**: 1일

### Phase 1: 메인넷 발행 (루트 A/B 확정 후)
- **담당**: 대구루 (회장님 예산 승인 게이트)
- **입력**: Phase 0 산출물, 승인된 예산
- **출력**: mainnet 토큰 + LP 풀 (루트 A: pump.fun → PumpSwap 그래듀에이션 / 루트 B: Raydium CPMM 직접 + LP 소각·락)
- **예상 시간**: 0.5일

### Phase 2: DEX 노출 확인
- **담당**: 대구루
- **입력**: mainnet 풀 주소
- **출력**: DexScreener/GeckoTerminal 인덱싱 스크린샷, Jupiter 라우팅 확인, 메타데이터 표시 검증
- **예상 시간**: 0.5일

### Phase 3: 사실 기반 이벤트 마케팅 1회
- **담당**: 대구루 (회장님 이벤트 선택 승인)
- **입력**: 확보된 토큰·풀, 연동 이벤트(후보: 삼체 만화 EP 공개 등 자체 콘텐츠)
- **출력**: 고지 문구 포함 홍보물 게시 + 게시 로그
- **예상 시간**: 0.5일

### Phase 4: 관측 대시보드 + 효과 리포트
- **담당**: 대구루
- **입력**: DexScreener/Raydium API, 마케팅 실행 시점 기록
- **출력**: 가격·거래량·홀더·유동성 대시보드 + 이벤트 전후 비교 리포트
- **예상 시간**: 1일

## 의존성
- mainnet 예산 승인(회장님) — Phase 1 착수 전 필수
- 발행 루트 결정(A/B) — Phase 1 설계 확정에 필요
- 마케팅 연동 이벤트 결정 — Phase 3 착수 전 필수
- CLE2-14 ai-solana-agent 부활 여부 — 스크립트 소재 위치 결정

## 리스크
- 법 리스크: 시세조작·사기적 부정거래로 오인될 소지 → 가드레일 6항목 준수, 마케팅물 사전 승인으로 완화
- 자금 손실: 초기 유동성 SOL 전액 소모 가능성 → 예산 상한제로 완화
- 카피캣 토큰: 유사 이름·주소 위조 (LEEK 사례에서도 4종 확인) → 공식 주소 단일 채널 고지로 완화
- 기술 리스크: 루트 A 그래듀에이션 미달 → 풀 미존재 상태 장기화. 루트 B는 CPMM 풀 파라미터 오설정 가능 → devnet 리허설로 완화
