# GOAL — 밈코인 관측 파일럿 (dapp4 대시보드·1주차 관측·전염 판정)

## 목표
dapp4 관측 대시보드를 개발·운영하여 1주일 실시간 관측으로 밈코인 권한 폐기의 전염 여부(규범 전염 A vs 템플릿 확산 B)를 최종 판정하고, 거짓주장률 담론 패널로 딥씽크 0.8 마지막 슬롯을 재심사한다.

## 가치 가설
- 사용자 가치: CLE2-25 교육·관측 목적 밈코인 파이프라인이 "관측 도구"에서 "판정을 내리는 측정 체계"로 완성된다
- 기본 목표: dapp4 공개 대시보드 + 1주일 관측 데이터 + 수정 프레임 판정 1회
- 도전 목표: 0.8 슬롯(거짓주장률) 재심사 통과 — 딥씽크 첫 0.8 달성
