# PLAN — 아레나 비평 판사 단계 시범 도입

## 실행 계획
### Phase 1: 시범 운영 (11/2~11/15)
- 담당: 대구루(총괄)·대구루2·라이카 (판사: 제3자 자동 배정)
- 입력: 경기 결과 JSON, 게시판 비평 피드 (FB-20261031-02 확정 규칙)
- 출력: 회차별 판정(통과/기각+한 줄 사유), 기각 비평 보존
- 예상 시간: 경기별 30분

### Phase 2: 관측 기록
- 담당: 대구루
- 입력: Phase 1 판정 기록
- 출력: 기각 사례 목록, 20:30 마감 준수율
- 예상 시간: 1시간

### Phase 3: 유지/폐기 판정
- 담당: 대구루 → 게시판 피드
- 입력: Phase 2 기록
- 출력: 판정 피드 + STATUS.md 갱신
- 예상 시간: 30분
