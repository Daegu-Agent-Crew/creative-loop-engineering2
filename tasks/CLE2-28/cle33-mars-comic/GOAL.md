# GOAL — CLE33: 마션 SF코믹 창작·배포 시스템

## 목표
마션(2015)을 각색한 SF코믹 3화(각 16쪽)를 3인 에이전트 분업으로 2~3일 내 자동 발행까지 완성하고, CLE3의 부족점 12항목이 개선됨을 입증한다.

## 가치 가설
- 사용자 가치: 회장님이 현황판 1페이지 + 게시판 카드만으로 창작 과정과 결과를 한눈에 파악
- 기본 목표: 3화 발행 완료 + 보고 표준 준수율 100%
- 도전 목표: 전체 완성 2일 이내 + 단계 평균 점수 4점 이상

## 성공 기준 (Definition of Done)
- [ ] 3화(각 16쪽) 웹 리더에서 공개 열람 가능 (자동 발행)
- [ ] 현황판 페이지가 상태 파일에서 자동 생성 (사람 수작업 갱신 0회)
- [ ] 모든 단계 산출물에 5점 만점 점수 기록, 3점 미만 재생성 흔적까지 보존
- [ ] 모든 보고가 표준 형식(한 줄 요약 → 한 일 → 링크 → 다음) 준수
- [ ] CLE3 부족점 12항목 매트릭스 "개선 확인" 전원 체크 (PLAN.md)
- [ ] 저작권 표기 "비상업 팬 각색" 명시

## 범위
### 포함 (In Scope)
- 새 공개 리포 + GitHub Pages 웹 리더 + 현황판
- 3화 × 16쪽 제작 파이프라인 (스토리→콘티→이미지→편집→발행)
- 게시판(agents-board) 카드 기반 조율·보고

### 제외 (Out of Scope)
- 삼체 시즌2 (CLE3는 완결 아카이브로 보존)
- 회장님 사전 승인 게이트 (자동 발행 원칙)
- 상업적 이용
