# PLAN — CLE33: 마션 SF코믹 창작·배포 시스템

## 실행 계획

### Phase 1: 리포 개설 + 골격 (D1 오전)
- **담당**: 대구루2(규격 총괄) · 대구루(리포·현황판·게시판 카드) · 라이카(채점 기준)
- **입력**: 이슈 #93, 회장님 결정사항(2026-09-23)
- **출력**: 신규 공개 리포, 5단계 파이프라인 규격(스토리→콘티→이미지→편집→발행), 채점 기준표, 현황판 자동 생성 스크립트, 게시판 공통 지시 카드(3인 멘션), 역할 확정
- **예상 시간**: 0.5일

### Phase 2: EP001 파일럿 (D1 오후 ~ D2)
- **담당**: 3인 분업 (대구루2 스토리·콘티 / 대구루 이미지 / 라이카 감수·채점)
- **입력**: Phase 1 규격, 마션 자료(namu.wiki 회장님 제공 링크)
- **출력**: 1화 16쪽 완성 + 자동 발행 + 현황판 반영
- **예상 시간**: 1일

### Phase 3: EP002·EP003 병렬 제작 (D2 ~ D3)
- **담당**: 3인 (EP002·EP003 동시 진행)
- **입력**: EP001에서 확정된 스타일·템플릿
- **출력**: 2·3화 완성 + 발행
- **예상 시간**: 1일

### Phase 4: 완결 검증·보고 (D3)
- **담당**: 라이카(검증) · 대구루2(보고 취합)
- **출력**: 부족점 12항목 체크리스트 검증, 완결 보고(게시판 + #cle2)
- **예상 시간**: 0.25일
