# PLAN — CLE4: 감각 기반 창작 에이전트 시스템

## 실행 계획

### Phase 1: 시스템 프롬프트 및 파일 구조 구축
- **담당**: 라이카
- **입력**: CLE4-blueprint.md (설계도 완료)
- **출력**:
  - `cle4/SYSTEM.md` — 시스템 프롬프트 (Role + 6원칙 + 금지사항)
  - `cle4/CONSTRAINTS.md` — 서사 제약 규칙
  - `cle4/PROMPT-templates/` — 이미지 프롬프트 템플릿
  - `cle4/INPUT-template.md` — 입력 템플릿
  - `cle4/PIPELINE.md` — 내부 프로세스 문서
  - `cle4/seed-registry.yaml` — 복선 등록부 (초기)
  - `cle4/character-deficits.yaml` — 캐릭터 결핍 정의 (삼체)
- **예상 시간**: 1세션

### Phase 2: 삼체 EP003 프로토타이핑
- **담당**: 라이카
- **입력**: 회장님의 감각/그리움 입력 + SYSTEM.md
- **출력**:
  - `cle4/projects/samjae/EP003/` 전체 파일
  - senses.yaml (감각 추출 결과)
  - longing-map.yaml (그리움 매핑)
  - structure.yaml (구조 설계 — McKee/Snyder 숨겨서)
  - reader-sim.md (5인 독자 시뮬레이션 결과)
  - storyboard.html (스토리보드)
  - 핵심 패널 1~2컷 이미지 생성
- **예상 시간**: 2세션

### Phase 3: 회장님 피드백 및 수정
- **담당**: 회장님 + 라이카
- **입력**: EP003 스토리보드 + 이미지
- **출력**: 수정안 또는 승인
- **예상 시간**: 1세션 (회장님 응답에 따라 변동)

### Phase 4: 독자 시뮬레이션 비교 검증
- **담당**: 라이카
- **입력**: CLE3 EP003 결과 vs CLE4 EP003 결과
- **출력**: 5인 독자 시뮬레이션 비교표, 개선 효과 분석
- **성공 기준**: CLE3 평균 5.0/10 → CLE4 평균 6.0/10 이상
- **예상 시간**: 1세션

### Phase 5: 시스템 개선 및 EP004~005 확장
- **담당**: 라이카
- **입력**: EP003 검증 결과 + 회장님 피드백
- **출력**: SYSTEM.md 개정, EP004~005 적용
- **예상 시간**: 2세션

## 의존성
- 회장님의 초기 입력 (EP003 감각/그리움) — Phase 2 시작 조건
- Raphael AI 가용성 — Phase 2 이미지 생성
- CLE3 기존 결과물 — Phase 4 비교 기준

## 리스크
- **가상 독자의 한계**: "가상 독자는 결국 작자의 분신" — 회장님 실제 반응으로 교차 검증 필요
- **이미지 생성 품질**: 김환기식 "무심함"이 AI 이미지에서 구현 가능한지 미지수
- **과도한 철학화**: 설계는 좋지만 실제 작업에서 너무 관념적이 될 위험 — Phase 2에서 실용성 검증 필수
