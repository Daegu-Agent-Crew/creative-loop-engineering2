# GOAL — CLE4: 감각 기반 창작 에이전트 시스템

## 목표
김환기 화백의 예술 철학을 뼈대로 삼고, 거장 만화의 연출 원칙을 근육으로 삼아, 회장님이 주시는 감각과 그리움을 입력받아 만화/글 콘텐츠로 번역하는 창작 시스템을 구축한다. 회장님의 개입은 "입력 1~3줄 + 피드백" 두 곳만으로 최소화한다.

## 배경
- CLE1(키워드 기반)과 CLE3(구조론 기반)의 근본 한계: 둘 다 "왜 그리는가"가 없었다
- 김환기 철학 연구에서 6원칙 도출: 감각의 기억, 그리움의 인식, 무심함의 미학, 특수성→보편성, 작품이 곧 진실, 절실함
- 회장님이 제공한 거장 가이드(토리야마/데즈카/오다)를 소화하여 연출 원칙으로 통합
- 독자 시뮬레이션(5인 가상 독자) 프로토타입 검증 완료

## 성공 기준 (Definition of Done)
- [ ] CLE4 시스템 프롬프트가 설계도대로 구현됨 (6원칙 + 금지사항 + 작품별 적응)
- [ ] 입력→출력 파이프라인이 작동함 (감각 추출 → 그리움 매핑 → 구조 설계 → 독자 시뮬레이션 → 무심함 검증)
- [ ] 삼체 EP003 "세 개의 태양"으로 첫 프로토타이핑 완료
- [ ] 회장님 개입 지점이 2곳(입력+피드백)만으로 제한됨
- [ ] 이미지 프롬프트 구조([연출]+[감각]+[스타일]+[작화])가 Raphael/Pollinations에서 작동함
- [ ] 서사 제약(결핍의 법칙, 인과율 추적, 복선 시드-수확)이 실제 작업에 적용됨
- [ ] 독자 시뮬레이션 평균 6/10 이상 달성 (CLE3의 5.0/10에서 개선)

## 범위
### 포함 (In Scope)
- CLE4 시스템 설계 및 구현
- 삼체 EP003 프로토타이핑 (첫 테스트 케이스)
- 김환기 철학 기반 6원칙 시스템 프롬프트
- 거장 연출 원칙 소화 및 통합 (토리야마/데즈카/오다)
- 독자 시뮬레이션 5인 패널 통합
- 이미지 생성 프롬프트 템플릿 (Raphael/Pollinations 대응)
- 서사 제약 규칙 (결핍, 인과율, 복선)
- 파일 구조 및 디렉토리 체계

### 제외 (Out of Scope)
- CLE3 백포팅 (CLE4는 새 시스템으로 기존 CLE3를 대체)
- 전체 에피소드 완성 (EP003 일부로 프로토타입 검증이 목표)
- 웹 UI 구축 (설계도 단계, 실행은 CLI/에이전트 기반)
- 다른 작품 적용 (삼체 우선, 이후 확장)
