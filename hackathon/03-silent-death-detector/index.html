🔕 조용한 죽음 탐지기

작업이 실패하면 알림이 옵니다. 그런데 작업이 아예 안 돌면 아무 일도 일어나지 않습니다. 주기 작업 목록을 붙여 넣으면 "늦은 것"과 "죽은 것"을 갈라 주고, 실패 알림으로는 영원히 못 잡는 작업을 찍어 줍니다. 입력한 내용은 브라우저 밖으로 나가지 않습니다.

    침묵 감시 카드

    
      
    
    
    
  
    

    


    
  
    
    
    2026-09-28 ~ 10-04 · 자동화 5개가 조용히 죽어 있던 6일
    
    
    이 도구는 제가 당한 사고에서 나왔습니다. 주기 작업 5개가 enabled: true를 유지한 채 단 한 번도 돌지 않았고,
    실패 알림은 한 통도 오지 않았습니다. 실패한 실행이 0건이었기 때문입니다.
    
    
    어떻게 보였나
    
    
      
      
    • cron list — 5개 전부 enabled: true, 상태 ok
      • 
      
    • 스케줄러 자체도 enabled: true, triggersEnabled: true
      • 
      
    • 실패 알림 설정 정상 (failure-alert after 1)
      • 
      
    • 그런데 nextWakeAtMs가 6일 전 시각에 멈춰 있었음
      • 
    
    
    
    왜 못 잡았나
    
    
      
      
    • 실패 알림은 실행된 뒤 실패한 것만 셉니다. 실행이 0건이면 셀 것도 0건입니다.
      • 
      
    • enabled는 "돌 예정"이라는 의도이지 "돌았다"는 증거가 아닙니다.
      • 
      
    • 작업을 감시하는 장치를 같은 스케줄러에 두면, 스케줄러가 죽을 때 감시도 같이 죽습니다.
      • 
      
    • 보고된 uptime이 실제 프로세스 수명과 달랐습니다 — 지표 하나만 믿으면 오진합니다.
      • 
    
    
    
    무엇이 진짜 신호였나
    
    
      
      
    • 마지막 성공 시각과 현재 시각의 차이. 이것만이 거짓말을 하지 않습니다.
      • 
      
    • 그 차이를 스케줄러 바깥에서 재는 것. 안에서 재면 같이 죽습니다.
      • 
    
    
    
    진단 탭의 "예시: 실제 장애" 버튼이 이 사고의 실제 데이터입니다.
